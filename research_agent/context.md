# 项目背景（给服务器上的调研 agent 读；由 Claude 在每次整合后更新）

> 主文档：`docs/geometry_fusion_research.md`（v2）。这里只放筛选和精读需要的摘要。

## 我们在回答什么
- 任务：水下开放词汇语义分割（UOVS），免训练框架 Earth2Ocean（E2O，CVPR'26）。E2O 用 Depth Anything V2 编码器 block-11 特征的自相似替换 CLIP 末层注意力，但**深度图本身被丢弃**。
- 问题 1：怎样**真正**利用几何/深度（显式深度序、深度不连续、3D 邻近、法向、物理量），而不只是换一个 DINOv2 家族的特征？
- 问题 2：怎样做好多源特征融合（CLIP/DINOv2/SAM/RADIO/深度模型的特征、注意力、区域、决策）？
- 已知瓶颈：识别（文本头 33% vs 视觉质心 85%）远大于分组（完美分组只 +1.3 mIoU）。

## 分类维度（精读卡片要填）
- 几何信息：I0 深度模型编码器特征（隐式）；I1 远近顺序/前景"凸起"；I2 深度不连续；I3 3D 邻近；I4 法向；I5 物理量（衰减/散射）；I6 度量尺度。
- 注入位置：input 输入融合；attention 注意力/亲和；post 后处理/上采样精修；region 区域/提示（SAM 等）；training_signal 只作训练信号。
- 设定：training-free / light-training（只用无标签数据的一次性预训练等）/ training。

## 当前规则（顶会证据归纳，等待更多证据支持、反驳或细化）
- R1 深度主要改善定位，很少改善识别。
- R2 直接融合估计深度常常无益；有效做法需要门控/可靠性、浅层查询、训练辅助或结构先验。
- R3 骨干越强，深度的边际增益越小。
- R4 结果对深度质量的依赖弱于预期（不能用"深度越好效果越好"证明几何作用）。
- R5 容量、空间先验、通用特征三类混淆很常见（需同构非几何对照、仅空间项、打乱深度、特征复制对照）。
- R6 水下：相对远近可用，度量深度不可用。
- R7 免训练多源范围/亲和融合在自然图像上增益大，本项目 P0 分组余量小，可能获益的是多类场景（SUIM/DUT）。
- R8 训练式几何融合的增益主要在已见类和定位；开放词汇未见类很小。

## 候选方案卡片（which_cards 用这些编号；都不对应就用 new）
- D0 诊断现有 A4 增益是否"几何的"。
- G1 深度前景/背景通道（远近序、"凸起"先验，免训练）。
- G2 3D 感知亲和（深度差/空间距离调制注意力；深度高频锐化亲和）。

- G4 深度模型多层特征、注意力 key、DPT 解码特征。
- G5 区域先验：SAM/SAM2 范围约束、深度提示、3D 切割。
- G6 物理复原用于识别。
- G7 尺寸先验（度量深度）。
- M1 亲和层多源融合（注意力平均、共识、门控、RADIO 代理）。
- M2 决策层多源融合（文本 + 视觉原型 + MLLM）。
- T1 训练式门控融合（单列）。
